Λ Activer Livechat (session perso)

Ce lien a été généré avec /lienperso. Une session temporaire sera configurée pour ton compte Discord uniquement.

Conditions d’utilisation (résumé)

1. Livechat affiche des médias (images, GIF, vidéos, audio) en overlay pendant que tu joues ou utilises ton PC.

2. La session « lien personnel » installe un programme temporaire dans un dossier temp Windows, pré-configuré avec le token bot et ton User ID fournis dans le lien signé.

3. Ce programme se supprime automatiquement au prochain démarrage de Windows (entrée RunOnce). Tu peux aussi utiliser le lien d’arrêt fourni avec !stop / /stopguest.

4. Tu restes responsable du contenu envoyé/reçu sur les serveurs concernés. N’accepte un lien que s’il provient d’une source de confiance (ton serveur / ton bot Livechat).

5. Le lien est signé et à durée limitée. Ne le partage pas publiquement : il contient des informations de configuration sensibles.

6. En cliquant sur « Activer le Livechat », tu acceptes ces conditions et autorises le lancement du protocole livechat://guest/… (ou le bootstrap) sur cette machine.

Prérequis : Livechat Setup.exe déjà installé une fois sur ce PC (protocole + Viewer).
Si rien ne se passe, autorise l’ouverture du protocole dans le navigateur.
